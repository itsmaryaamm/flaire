# Notice

Flaire is an independent implementation. The product idea (a local-first spend-control layer
for AI agents, with a simulated demo) is inspired by Shotoku (https://github.com/shotoku-dev/shotoku, MIT).
No Shotoku source code was copied. Flaire was written from scratch, in plain JavaScript with no
dependencies, and adds Saudi-specific features: SAR in halalas, SAR/USD peg, Arabic and English
messages and dashboard, government payment review rule, Saudi working-week schedule.

Some command names (demo, init, authorize, approve, status, history) are similar to Shotoku's because
they are the natural verbs for this kind of tool. Before any public launch, have the team decide on its own
command names and branding, and check the Flaire name for trademark and domain conflicts.

Simulated money only. Flaire does not move, hold or issue real money, and an "allow" is not a bank authorization.
